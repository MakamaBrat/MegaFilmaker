# 🎬 Video Merger Telegram Bot

Telegram бот для объединения видео с красивыми переходами, эффектами и поддержкой различных форматов. Бот работает на **Vercel** и отправляет готовые видео прямо в Telegram.

## 🌟 Особенности

- ✅ **Объединение видео** - соедини два видео в одно
- ✨ **Переходы и эффекты** - Fade, Slide, Zoom, Cut
- 🔊 **Обработка звука** - одновременно, по очереди или без звука
- 📱 **Telegram интеграция** - результаты отправляются прямо в чат
- ⚡ **Быстрое объединение** - без эффектов, мгновенно
- 🎨 **Красивый интерфейс** - интуитивные кнопки и меню
- 📊 **Поддержка форматов** - MP4, AVI, MOV, MKV, FLV, WebM

## 📋 Требования

- **Python 3.8+**
- **Vercel аккаунт** (бесплатно на vercel.com)
- **Telegram Bot Token** (от @BotFather)
- **FFmpeg** установленный на сервере Vercel

## 🚀 Быстрый старт

### Шаг 1: Получить Telegram Bot Token

1. Напиши @BotFather в Telegram
2. Отправь `/newbot`
3. Следуй инструкциям
4. Скопируй токен (выглядит так: `123456789:ABCdefGHIjklmNOPqrSTUVwxyz`)

### Шаг 2: Подготовить репозиторий

```bash
# Клонировать или скачать файлы проекта
git clone <репо>
cd video-merger-bot

# Скопировать .env.example в .env
cp .env.example .env

# Заполнить переменные окружения
# Открыть .env и вставить свой TELEGRAM_BOT_TOKEN
```

### Шаг 3: Развернуть на Vercel

#### Способ 1: Через CLI (рекомендуется)

```bash
# Установить Vercel CLI
npm i -g vercel

# Войти в свой аккаунт Vercel
vercel login

# Развернуть проект
vercel

# Во время развёртывания введи:
# - Название проекта: video-merger-bot
# - Выбери Python как framework
# - Установи переменные окружения:
#   TELEGRAM_BOT_TOKEN = твой_токен
#   WEBHOOK_URL = https://твой-домен.vercel.app
```

#### Способ 2: Через веб-интерфейс Vercel

1. Зайди на https://vercel.com
2. Нажми "New Project"
3. Импортируй свой Git репозиторий
4. Во время конфигурации добавь переменные окружения:
   - `TELEGRAM_BOT_TOKEN` = твой токен
   - `WEBHOOK_URL` = твой домен на Vercel

### Шаг 4: Активировать вебхук

После развёртывания вызови эндпоинт для активации вебхука:

```bash

```

Или просто открой в браузере:

### Шаг 5: Тестирование

1. Найди своего бота в Telegram по имени (которое дал BotFather)
2. Отправь `/start`
3. Следуй инструкциям бота

## 📖 Как использовать бота

### Начальный экран
Отправь `/start` чтобы увидеть главное меню

### Загрузка видео
1. Нажми "Начать объединение видео"
2. Загрузи **первое видео** (просто отправь видеофайл)
3. Загрузи **второе видео**

### Выбор параметров

Быстрое объединение:
- Переход: резкий (Cut)
- Без эффектов
- Готовый результат за минуты

Объединение с эффектами:
- Выбери тип переходов:
  - **Fade** ⚡ - плавный переход (1-2 сек)
  - **Slide** ↔️ - скользящий переход (0.5-1 сек)
  - **Zoom** 🔍 - переход с увеличением (1-2 сек)
  - **Cut** ✂️ - резкий переход (0 сек)

- Выбери длительность переходов (0.5 - 2 секунды)

- Выбери обработку звука:
  - **Оба одновременно** 🔊 - звук обоих видео наложится
  - **По очереди** 📱 - сначала звук первого, потом второго
  - **Без звука** 🔇 - удалить весь звук

### Результат
Готовое видео будет отправлено в Telegram сообщением

## 🐛 Решение проблем

### Проблема: "Webhook not working"
**Решение:**
- Проверь, что `WEBHOOK_URL` правильный
- Вызови `/setup-webhook` ещё раз
- Перезапусти проект на Vercel

### Проблема: "Video upload fails"
**Решение:**
- Проверь размер видео (макс 500 MB)
- Убедись, что формат поддерживаемый (MP4, AVI, MOV, MKV)
- Попробуй загрузить видео меньшего размера

### Проблема: "Merge takes too long"
**Решение:**
- Это нормально для больших видео (200+ MB)
- Обычно занимает 5-15 минут
- Бот продолжит работу в фоне

### Проблема: "FFmpeg not found"
**Решение:**
- FFmpeg должен быть установлен на Vercel
- Добавь в `vercel.json`:
```json
{
  "buildCommand": "apt-get update && apt-get install -y ffmpeg && pip install -r requirements.txt"
}
```

## 💾 Сохранение видео

Временные файлы автоматически удаляются после:
- Успешной загрузки в Telegram (24 часа)
- Ошибки при обработке (сразу)

Основное видео сохраняется на сервере Telegram (неограниченное время) по файлу ID.

## 🔐 Безопасность

- Все запросы идут через HTTPS
- Проверка подлинности через токен Telegram
- Временные файлы хранятся в `/tmp` (автоматически очищаются)
- Нет логирования персональных данных
