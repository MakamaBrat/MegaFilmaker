## Создание Telegram бота

### Шаг 1: Найти BotFather в Telegram

1. Открой Telegram
2. В поиске введи `@BotFather`
3. Нажми на аккаунт (с синей галочкой)
4. Нажми "Start"

### Шаг 2: Создать новый бота

1. Отправь команду: `/newbot`
2. BotFather спросит имя бота:
   - Например: `My Video Merger`
3. BotFather спросит username:
   - Должен быть уникальный
   - Например: `my_video_merger_bot` (должен заканчиваться на `_bot`)

### Шаг 3: Получить токен

BotFather отправит сообщение с токеном:
```
Here is your bot token:
123456789:ABCdefGHIjklmNOPqrSTUVwxyz
```

**⚠️ Важно:** Сохрани этот токен в безопасном месте! Это пароль для твоего бота.

### Шаг 4: Настроить BotFather (опционально)

Если хочешь, отправь команды BotFather:

```
/setcommands

После этого напиши:
start - Начать новый проект
help - Справка по использованию
cancel - Отменить текущий проект
```

## Развёртывание на Vercel

### Способ 1: Через Vercel Dashboard (графический интерфейс)

#### Шаг 1: Зайди на Vercel

1. Открой https://vercel.com
2. Нажми "Sign in" и выбери "GitHub"
3. Авторизируйся через GitHub

#### Шаг 2: Создать новый проект

1. Нажми кнопку "New Project"
2. Найди в списке свой репозиторий `video-merger-bot`
3. Нажми "Import"

#### Шаг 3: Настроить проект

На странице конфигурации:

1. **Project Name:** оставь `video-merger-bot`
2. **Framework Preset:** выбери `Python`
3. **Root Directory:** оставь пусто (.)

#### Шаг 4: Добавить переменные окружения

1. Нажми "Environment Variables"
2. Добавь переменные:

```
TELEGRAM_BOT_TOKEN = твой_токен_от_BotFather
WEBHOOK_URL = https://video-merger-bot-RANDOM.vercel.app
```

Домен Vercel будет генерироваться автоматически, или ты можешь выбрать кастомный домен.

#### Шаг 5: Развернуть

1. Нажми кнопку "Deploy"
2. Жди 2-3 минуты, пока идёт развёртывание
3. Когда завершится, ты увидишь ссылку на свой бот

**Важно:** Обнови `WEBHOOK_URL` на правильный домен после развёртывания!

### Способ 2: Через Vercel CLI (командная строка)

```bash
# Установить Vercel CLI
npm install -g vercel

# Войти в аккаунт
vercel login

# Перейти в папку проекта
cd ~/Projects/video-merger-bot

# Развернуть
vercel

# Следуй инструкциям:
# - Выбери "Y" для связи с существующим проектом (если есть)
# - Или создай новый проект
# - Ввод переменных окружения:
#   TELEGRAM_BOT_TOKEN = твой_токен
#   WEBHOOK_URL = (Vercel скажет тебе URL после развёртывания)

# Повторное развёртывание
vercel --prod
```

## Активация вебхука

После развёртывания нужно активировать вебхук, чтобы бот получал сообщения от Telegram.

### Способ 1: Через браузер (самый простой)

1. Открой в браузере:
```
https://твой-домен.vercel.app/setup-webhook
```

2. Ты должен увидеть ответ JSON:
```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

3. Готово! Вебхук активирован ✅

### Способ 2: Через curl (командная строка)

```bash
curl https://твой-домен.vercel.app/setup-webhook
```

### Способ 3: Вручную (продвинутый)

```bash
# Замени значения
TOKEN="123456789:ABCdefGHIjklmNOPqrSTUVwxyz"
WEBHOOK_URL="https://твой-домен.vercel.app/webhook"

# Отправить запрос на Telegram API
curl -X POST https://api.telegram.org/bot$TOKEN/setWebhook \
  -d url=$WEBHOOK_URL
```

## Тестирование

### Проверка, что бот работает

#### Шаг 1: Найти бота в Telegram

1. Открой Telegram
2. Нажми на поиск (лупу)
3. Введи имя бота (то, которое дал BotFather)
4. Нажми на бота в результатах

#### Шаг 2: Запустить бота

1. Нажми кнопку "Start" или напиши команду `/start`
2. Бот должен ответить:
```
👋 Привет! 🎬 Добро пожаловать в Video Merger Bot
...
```

Если видишь это сообщение - поздравляю! Бот работает! 🎉

#### Шаг 3: Протестировать функциональность

1. Нажми "Начать новый проект"
2. Отправь первое видео (любое видео файл)
3. Бот должен ответить: "✅ Первое видео загружено!"
4. Отправь второе видео
5. Бот должен предложить варианты объединения

## ❓ Частые проблемы

### Проблема: "Webhook not returning 200 OK"

**Решение:**
```bash
# Проверить, что приложение работает
curl https://твой-домен.vercel.app/

# Должно вернуть статус приложения
```

### Проблема: "Bot doesn't respond"

**Решение:**
1. Убедись, что WEBHOOK_URL совпадает с доменом на Vercel
2. Вызови `/setup-webhook` снова
3. Жди ~30 секунд, пока Telegram обновит конфигурацию

### Проблема: "FFmpeg not found"

**Решение:**
FFmpeg уже включен в требования. Если не работает:
1. Пересоздай проект на Vercel (Redeploy)
2. Проверь логи Vercel

### Проблема: "Video merging takes too long"

**Решение:**
Это нормально! Для больших видео обработка может занять 10-30 минут.

### Проблема: "413 Payload Too Large"

**Решение:**
Видео слишком большое. Максимум 500 MB на видео.
