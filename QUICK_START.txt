🚀 БЫСТРЫЙ СТАРТ - ВИДЕО БОТА НА VERCEL

═══════════════════════════════════════════════════════════════

📋 ШАГ 1: ПОЛУЧИТЬ ТОКЕН БОТА (5 минут)
═══════════════════════════════════════════════════════════════

1. Открой Telegram
2. Найди @BotFather
3. Отправь: /newbot
4. Выбери имя бота (например: MyVideoMerger)
5. Выбери username (например: my_video_merger_bot)
6. Скопируй ТОКЕН (выглядит: 123456789:ABCdef...)

⚠️ Сохрани токен! Это главный пароль бота!


📋 ШАГ 2: СКАЧАТЬ И ПОДГОТОВИТЬ ФАЙЛЫ (5 минут)
═══════════════════════════════════════════════════════════════

1. Распакуй архив video-merger-bot.zip
2. Открой файл .env.example в текстовом редакторе
3. Замени:
   TELEGRAM_BOT_TOKEN = твой_токен_от_BotFather
   WEBHOOK_URL = https://твой-домен.vercel.app (узнаешь после развёртывания)
4. Сохрани файл как: .env (без расширения)


📋 ШАГ 3: ЗАГРУЗИТЬ НА GITHUB (5 минут)
═══════════════════════════════════════════════════════════════

1. Зайди на https://github.com
2. Создай новый репозиторий: video-merger-bot
3. В командной строке выполни:
   
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ТВ_ИМЕНИЕ/video-merger-bot.git
   git push -u origin main

Готово! Теперь файлы на GitHub


📋 ШАГ 4: РАЗВЕРНУТЬ НА VERCEL (5 минут)
═══════════════════════════════════════════════════════════════

1. Зайди на https://vercel.com
2. Зарегистрируйся (можно через GitHub)
3. Нажми "New Project"
4. Выбери "Import Git Repository"
5. Импортируй свой репозиторий video-merger-bot
6. На странице конфигурации:
   - Project Name: video-merger-bot
   - Framework: Python
7. Нажми "Environment Variables"
8. Добавь переменные:
   TELEGRAM_BOT_TOKEN = твой_токен
   WEBHOOK_URL = (узнаешь после первого Deploy, обновишь потом)
9. Нажми "Deploy"

Жди 2-3 минуты...

После развёртывания ты увидишь URL типа:
https://video-merger-bot-abc123.vercel.app

⚠️ ВАЖНО: Обнови WEBHOOK_URL на этот домен и переделай Deploy!


📋 ШАГ 5: АКТИВИРОВАТЬ ВЕБХУК (1 минута)
═══════════════════════════════════════════════════════════════

1. Открой в браузере:
   https://твой-домен.vercel.app/setup-webhook

2. Должно вывести:
   {"ok": true, "result": true}

Вебхук активирован! ✅


📋 ШАГ 6: ТЕСТИРОВАНИЕ (5 минут)
═══════════════════════════════════════════════════════════════

1. Открой Telegram
2. Найди своего бота (по названию, которое дал BotFather)
3. Нажми "Start" или отправь /start
4. Должно появиться главное меню

Если видишь меню - БРАВО! Бот работает! 🎉

❓ ЧАСТЫЕ ПРОБЛЕМЫ:
═══════════════════════════════════════════════════════════════

Проблема: "Бот не отвечает"
Решение:
  1. Убедись, что WEBHOOK_URL правильный
  2. Вызови /setup-webhook снова
  3. Жди 30 секунд
  4. Попробуй отправить сообщение ещё раз

Проблема: "Video upload fails"
Решение:
  1. Проверь размер видео (макс 500 MB)
  2. Убедись, что формат MP4 или AVI
  3. Попробуй меньшее видео

Проблема: "Merge takes too long"
Решение:
  1. Это нормально (5-15 минут для больших видео)
  2. Дождись завершения
  3. Для больших видео надо подождать
