## 📄 Описание каждого файла

### 🤖 Основные файлы приложения

#### `api_handler_full.py` ⭐
**Самый важный файл!**

Содержит:
- **FastAPI приложение** - REST API сервер
- **Telegram Bot Handler** - обработчик команд и сообщений от Telegram
- **Классы и функции:**
  - `VideoProject` - класс для хранения информации проекта
  - `send_message()` - отправка текстовых сообщений в Telegram
  - `send_video()` - отправка видео в Telegram
  - `download_file_from_telegram()` - скачивание видео с серверов Telegram
  - `process_and_merge_videos()` - основная функция объединения видео
  - `webhook_handler()` - обработчик вебхука от Telegram

**Что делает:**
1. Получает сообщения от Telegram через вебхук
2. Обрабатывает команды (/start, /help, /cancel)
3. Управляет загрузкой видео
4. Вызывает обработку видео
5. Отправляет результат обратно в Telegram

**Строки кода:** ~800

#### `video_processor.py` 🎬
Модуль для обработки видео с помощью FFmpeg.

Содержит:
- **Класс VideoProcessor** - главный класс для работы с видео
- **Методы:**
  - `merge_videos()` - объединение двух видео с переходами
  - `compress_video()` - сжатие видео для уменьшения размера
  - `get_video_info()` - получение информации о видео
  - `cleanup()` - удаление временных файлов

**Поддерживаемые переходы:**
- Fade (плавный переход)
- Slide (скользящий переход)
- Zoom (переход с увеличением)
- Cut (резкий переход)

**Строки кода:** ~400

### 🚀 Файлы развёртывания

#### `vercel.json` 🔧
**Конфигурация для Vercel (базовая версия)**

Что это делает:
- Указывает, какой файл запускать (`api_handler_full.py`)
- Настраивает маршруты (все запросы идут в Python)
- Указывает переменные окружения, которые нужны

Когда использовать: Если не нужны улучшенные лимиты Vercel

#### `vercel_advanced.json` ⚡
**Конфигурация Vercel (продвинутая версия)**

Улучшения:
- Увеличены лимиты памяти (3008 MB)
- Максимальное время выполнения 15 минут
- Оптимизирована сборка для FFmpeg

Когда использовать: Если обработка видео требует больше ресурсов

**Как использовать:**
```bash
# Переименуй файл
mv vercel_advanced.json vercel.json

# Или замени содержимое в vercel.json
```

#### `Dockerfile` 🐳
**Для запуска бота в Docker контейнере (локально)**

Что он делает:
1. Создаёт контейнер на базе Python 3.11
2. Устанавливает FFmpeg
3. Устанавливает Python зависимости
4. Создаёт временные директории
5. Запускает приложение на порту 8000

Когда использовать: Для локального тестирования перед развёртыванием

**Как использовать:**
```bash
docker build -t video-merger-bot .
docker run -p 8000:8000 -e TELEGRAM_BOT_TOKEN=твой_токен video-merger-bot
```

#### `docker-compose.yml` 🎼
**Удобный способ запустить приложение локально**

Что это делает:
- Автоматически собирает Docker образ
- Запускает контейнер
- Подключает переменные из .env файла
- Создаёт сетевое окружение

Когда использовать: Для удобного локального развития

**Как использовать:**
```bash
# Убедись, что установлен Docker Desktop

# Запусти
docker-compose up --build

# Приложение будет доступно на http://localhost:8000
```

## 🔑 Переменные окружения

| Переменная | Описание | Пример | Обязательная |
|-----------|---------|--------|-------------|
| `TELEGRAM_BOT_TOKEN` | Токен твоего бота от @BotFather | `123456:ABC...` | ✅ Да |
| `WEBHOOK_URL` | Домен приложения на Vercel | `https://bot.vercel.app` | ✅ Да |
| `PORT` | Порт для локального запуска | `8000` | ❌ Нет (по умолчанию 8000) |
| `FFMPEG_PRESET` | Скорость кодирования FFmpeg | `medium` | ❌ Нет |
| `VIDEO_QUALITY` | Качество видео | `high` | ❌ Нет |
| `MAX_VIDEO_SIZE` | Макс размер видео в байтах | `500000000` | ❌ Нет |

## 🚀 Быстрый старт (5 минут)

### Способ 1: Если ты хочешь быстро развернуть

1. **Создай бота в Telegram:**
   ```
   @BotFather > /newbot > выбери имя > получи ТОКЕН
   ```

2. **На Vercel:**
   - Создай аккаунт на vercel.com
   - Скачай файлы проекта
   - Загрузи на GitHub

3. **На GitHub:**
   - Создай репозиторий `video-merger-bot`
   - Загрузи туда файлы

4. **На Vercel:**
   - Import проект с GitHub
   - Добавь переменные окружения
   - Deploy!

5. **Активируй вебхук:**
   ```
   https://твой-домен.vercel.app/setup-webhook
   ```

## 📋 Что делает каждый файл во время работы

### При запуске:
1. `vercel.json` - говорит Vercel какой файл запустить
2. `api_handler_full.py` - стартует FastAPI приложение
3. `requirements.txt` - все зависимости должны быть установлены

### При получении сообщения от Telegram:
1. Telegram отправляет вебхук на `/webhook`
2. `api_handler_full.py` обрабатывает сообщение
3. Если видео - вызывается `video_processor.py`
4. `video_processor.py` использует `ffmpeg` (установлен в Dockerfile)
5. Готовое видео отправляется обратно в Telegram

### При развёртывании на Vercel:
1. `vercel.json` указывает как собирать
2. `requirements.txt` определяет зависимости
3. `.env` (на Vercel) предоставляет переменные
4. Всё собирается и запускается
