⚡ БЫСТРАЯ ИНСТРУКЦИЯ (5 МИНУТ)

═══════════════════════════════════════════════════════════════

ШАГ 1️⃣ - ПОЛУЧИТЬ ТОКЕН БОТА
═══════════════════════════════════════════════════════════════

1. Открой Telegram
2. Найди @BotFather
3. Отправь: /newbot
4. Выбери имя и username для бота
5. Скопируй ТОКЕН (выглядит: 123456789:ABCdef...)

⚠️ Сохрани токен! Он нужен дальше!


ШАГ 2️⃣ - ПОДГОТОВИТЬ ФАЙЛЫ
═══════════════════════════════════════════════════════════════

1. Распакуй архив video-merger-bot.zip
2. Открой файл .env.example
3. Замени строку:
   TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
4. Сохрани файл как: .env (без .example!)


ШАГ 3️⃣ - ЗАГРУЗИТЬ НА GITHUB
═══════════════════════════════════════════════════════════════

Откройе CommandLine (терминал) в папке проекта:

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВ_ИМЕНИЕ/video-merger-bot
git push -u origin main

Замени ТВ_ИМЕНИЕ на своё имя пользователя на GitHub


ШАГ 4️⃣ - РАЗВЕРНУТЬ НА VERCEL
═══════════════════════════════════════════════════════════════

1. Зайди на https://vercel.com
2. Зарегистрируйся (можно через GitHub)
3. Нажми "New Project"
4. Выбери "Import Git Repository"
5. Импортируй свой репозиторий video-merger-bot
6. Нажми "Deploy"

Жди 1-2 минуты...

После Deploy ты увидишь URL:
https://video-merger-bot-XXXXX.vercel.app


ШАГ 5️⃣ - ОБНОВИТЬ WEBHOOK_URL
═══════════════════════════════════════════════════════════════

1. На Vercel найди "Environment Variables"
2. Обнови WEBHOOK_URL на полученный URL:
   WEBHOOK_URL=https://video-merger-bot-XXXXX.vercel.app
3. Нажми "Save"
4. Нажми "Redeploy"


ШАГ 6️⃣ - АКТИВИРОВАТЬ ВЕБХУК
═══════════════════════════════════════════════════════════════

Открой в браузере:
https://video-merger-bot-XXXXX.vercel.app/setup-webhook

Должно вывести:
{"ok": true, "message": "Webhook set successfully"}

ГОТОВО! ✅


ШАГ 7️⃣ - ПРОТЕСТИРОВАТЬ БОТА
═══════════════════════════════════════════════════════════════

1. Открой Telegram
2. Найди своего бота по username (который дал BotFather)
3. Отправь /start
4. Должно появиться меню с кнопками

Бот работает! 🎉


═══════════════════════════════════════════════════════════════
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:
═══════════════════════════════════════════════════════════════

Проблема: Vercel не видит файлы
Решение: 
- Убедись, что файлы в правильной структуре:
  api/handler.py
  vercel.json
  requirements.txt
- Нажми "Redeploy" на Vercel


Проблема: Бот не отвечает на сообщения
Решение:
- Проверь, что WEBHOOK_URL правильный
- Вызови /setup-webhook снова
- Жди 30 секунд
- Попробуй отправить /start ещё раз


Проблема: При активации вебхука ошибка
Решение:
- Убедись, что WEBHOOK_URL установлен в переменных Vercel
- Проверь что домен правильный (без http://, только https://)
- Перепроверь TELEGRAM_BOT_TOKEN (не должно быть пробелов)
